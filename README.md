GTC code for a variety of bioinformatics tasks, written by members of the Whitehead Institute Bioinformatics and Research Computing group.

For all code, executing the script by itself should return a summary and a usage statement. Each directory includes code, sample input and output, and sample commands (in README).

Code is organized by programming language, but since all scripts are designed to be run on the command line, independently of language, this division is not so practically meaningful.
